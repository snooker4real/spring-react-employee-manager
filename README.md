# spring-react-employee-manager

**Stack** : Java 11, Maven, Spring Boot 2.6.3, MySQL

## Démarrage

### `employee-system-api/`

```bash
cd employee-system-api
./mvnw clean install   # construire et tester
./mvnw spring-boot:run   # démarrer l'application
./mvnw test   # lancer les tests
```
